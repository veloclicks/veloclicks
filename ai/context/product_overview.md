# Product Overview

Veloclicks is a cycling analytics platform focused on turning ride and workout data into useful performance insight.

The product combines deterministic analysis with LLM-generated interpretation. Deterministic logic is used wherever metrics, classifications, and repeatable physiological reasoning can be made explicit. LLMs are then used to generate narrative assessment, coaching-style explanation, and higher-level interpretation from a compact structured summary.

The product is intended to go beyond generic training platforms by:
- interpreting real-world outdoor rides, not just perfectly structured indoor workouts
- identifying meaningful training stimulus from messy ride data
- combining physiology-informed rules with flexible language-based explanation
- prioritising interpretability over opaque "AI" claims

Current and emerging product themes include:
- workout classification
- interval detection and interval summarisation
- warmup detection
- effective training stimulus identification from unstructured rides
- interval matrix style summaries by duration and intensity
- compact JSON summaries for LLM input
- narrative coaching feedback grounded in deterministic facts

The product should favour:
- explainability
- compact data contracts
- modular analysis stages
- clear distinction between facts, findings, and narrative
- architecture that supports iteration on analysis logic without destabilising the rest of the system
