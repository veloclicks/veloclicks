# Structural Architecture Review Playbook

## Architect Behaviour for this playbook

### Output Format
Structure analysis with clearly labeled phases:

### Phase 1: [Name]
**Effort**: X hours
**Risk**: Low/Medium/High
1. Step description
2. Step description

### Phase 2: [Name]
...

### What to Include
- Current state assessment
- Specific violations (with code examples)
- Target architecture
- Migration path (phases)
- Risks and trade-offs

### Tone
Be direct and specific. Reference actual code. Propose concrete solutions, not vague recommendations.
